# Форматирование отчёта (приложение со скринами)

Этот проект генерирует ежедневный DOCX через `tools/generate_daily_ad_report.py`.

## Правило “4 фото на страницу”

В приложении со скриншотами используется сетка **2×2**:
- 4 скрина на страницу
- в каждой ячейке: подпись `канал — ссылка` + картинка
- ширина картинки под 2 колонки: ~`3.15"` (Inches)

Реализация: функция `_append_screenshots_grid()` в `tools/generate_daily_ad_report.py`.

## Как сохраняется первая страница

Чтобы пункты **1–8** не разъезжались на несколько страниц из‑за длинного списка ссылок:
- список ссылок под пунктом 1 печатается **одной строкой** (`Ссылки: ...`) вместо буллетов по одному на строку.

Если ссылок станет слишком много и опять начнёт распирать 1‑ю страницу — решение простое:
- сокращать ссылки (например, печатать только `t.me/<канал>` без `/post_id`), или
- переносить “Ссылки” на отдельную страницу сразу после пункта 8.
